Parameter sets

The table below summarises the parameter sets currently obtained from the recorded flag-transitive group-type data files. The data are rebuilt automatically from the corresponding GAP files, excluding the Transitive groups and Primitive groups folders, whenever the website is generated.

Click a parameter-column heading to sort the table in ascending numerical order.
The Number of designs column gives the number of recorded designs with the corresponding parameter set.
The Group column lists the groups from which the parameter set is obtained. Group names are separated by commas, and each group name links to the corresponding raw GAP file.

No parameter sets are currently available.
