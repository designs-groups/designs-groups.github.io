Parameter sets

The table below summarises the parameter sets currently obtained from the recorded flag-transitive .g files in the Alternating groups, Affine groups, Classical groups, Exceptional groups, and Sporadic groups folders only.

Click a parameter-column heading once for ascending order, twice for descending order, and a third time to return to the original order sorted by parameters.
The Number of designs columns give the recorded counts obtained from the associated .g files; they are not the total number of all designs with that parameter set.
The Number of designs do not indicate the number of non-isomorphic designs with the parameter in the line.
The Group column lists the groups from which the parameter set is obtained. Group names are separated by commas, and each group name opens the corresponding GAP file on GitHub.
