Notes.
  • The table lists the recorded groups associated with each parameter set.
  • A group may appear in more than one column when designs with the same parameters have different point- or block-primitivity properties.
  • Several groups may occur in a single cell; each group is listed separately and links to its corresponding raw .g file.
  • The occurrence of the same group in different columns does not represent duplication; it indicates the corresponding different action properties.
  • Empty cells indicate that no recorded group with the corresponding property was found in the database.
  • Blank search fields are ignored; only the specified values of \(v,b,r,k,\lambda\) are used as search conditions.
  • When “Both” is selected, the results include both flag-transitive and block-transitive records.
